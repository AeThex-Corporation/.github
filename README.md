# AeThex Corporation - Organization Configuration

This repository contains the default community health files and organization profile for **AeThex Corporation**.

## Purpose

This `.github` repository serves as the centralized location for:

- 📋 Organization profile README (displayed on our GitHub organization page)
- 📝 Default community health files (CODE_OF_CONDUCT, CONTRIBUTING, etc.)
- 🔧 Reusable workflow templates
- ⚙️ Issue and pull request templates

## Structure

```
.github/
├── profile/
│   └── README.md          # Organization profile page
├── workflow-templates/     # Reusable GitHub Actions workflows
└── README.md              # This file
```
